# **App Name**: ManasMitra

## Product Direction

ManasMitra is a voice-first accessibility companion that helps users understand information, follow instructions, and complete everyday workflows through conversation.

## Core Features:

- Voice-first conversation: Users can speak naturally and get immediate assistance.
- Plain-language explanations: The assistant simplifies dense text, instructions, and messages.
- Multilingual support: The assistant can translate or restate content in a preferred language.
- Task assistance: The assistant can help users identify the next step in a process.
- Context retention: Short-term conversational memory keeps interactions coherent.
- Safety escalation: High-risk situations can be redirected to human support.

## Style Guidelines:

- Primary color: Calming teal (#4DB6AC) to signal trust and clarity.
- Background color: Soft warm neutral tones to keep the interface approachable.
- Accent color: Coral or lavender highlights for key actions.
- Body and headline font: 'PT Sans' sans-serif for readability and friendliness.
- Use simple icons and short labels to reduce cognitive load.
- Design a clean, accessible interface with clear spacing and a prominent voice control.
- Keep motion subtle and purposeful to avoid distraction.
